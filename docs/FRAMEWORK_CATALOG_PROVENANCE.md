# Framework catalog provenance

The global catalog stores publisher and edition metadata separately from requirement text. A version whose `provenance.contentAvailability` is `UNAVAILABLE` is intentionally empty: no requirement wording or count is inferred. An authorized administrator may import a permitted pack through the transactional requirement-pack endpoint; the parser requires source title, URL, retrieval date, exact declared count, unique references, domains, positive weights, and item-level validation.

The seeded catalog covers ISO/IEC 27001:2022, PCI DSS 4.0.1, the SOC 2 Trust Services Criteria with 2022 revised points of focus, NIST CSF 2.0, CIS Controls v8, GDPR Regulation (EU) 2016/679, the current HIPAA Security Rule baseline, NIST SP 800-53 Rev. 5, Nigeria Data Protection Act 2023, COBIT 2019, ISO 22301:2019, and ISO/IEC 27701:2025. Source URLs and the reason content is unavailable are stored on each edition. Licensed ISO and other unavailable texts are never reconstructed.
